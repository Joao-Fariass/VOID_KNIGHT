História do Jogo:

Void Knight é um jogo 2D de ação inspirado em Hollow Knight. O jogador controla um cavaleiro do vazio que deve enfrentar criaturas inimigas e sobreviver o maior tempo possível. A cada inimigo derrotado, o jogador ganha pontos e o desafio aumenta gradativamente, tornando a partida mais dinâmica e desafiadora. O objetivo é alcançar a maior pontuação possível e superar os recordes salvos no jogo.

Tecnologias Utilizadas:

Python 
Pygame
pyttsx3
JSON (armazenamento de pontuações)
cx_Freeze (geração do executável)
Git
